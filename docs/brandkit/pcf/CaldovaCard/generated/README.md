# generated/

`ManifestTypes.d.ts` is produced by the Power Platform CLI from
`ControlManifest.Input.xml`. It is **not** checked in.

```bash
pac pcf init --namespace Caldova --name CaldovaCard --template field --framework react
npm i && npm run build     # generates ManifestTypes.d.ts here
```

The unresolved import in `../index.ts` is expected until you run that.
